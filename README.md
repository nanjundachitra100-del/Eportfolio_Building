# 🌐 HTML & CSS Portfolio Classes

Welcome to my HTML and CSS learning repository! 🚀

This repository contains my practice work, class exercises, and small web development projects as I learn the fundamentals of building websites.

## 📚 Topics Covered

* **HTML Basics** – Headings, paragraphs, links, and text formatting.
* **CSS Styling** – Text colours, background colours, and fonts.
* **Box Model** – Margin, padding, borders, and width.
* **HTML Lists** – Ordered and unordered lists.
* **HTML Tables** – Creating tables using rows and columns.
* **Links and Images** – Adding hyperlinks and images to webpages.
* **CSS Selectors** – Styling elements using tags, classes, and IDs.
* **Page Layout** – Aligning and organizing webpage elements.
